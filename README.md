# Ticketing-System
Ticketing System – Kanban Workflow Board

# Features
- 📌 Drag-and-drop Kanban board with customizable status columns (Backlog, In Progress, Completed, On Hold)
- 📝 Create, edit, assign, and delete tickets
- 🧑‍💻 User roles for Admin, Developer, and Viewer
- 📊 Ticket filtering by status, priority, or assignee
- Legends filtering like urgent, high, medium and low

# ⚙️ Tech Stack
- Frontend: React with drag-and-drop UI
- Backend: Node.js / Express based microservice
- Database: MongoDB / PostgreSQL 
- Communication: RESTful API
